# El Invitado

Ojos, mano, silueta incompleta y tinta de esquina con transparencia real. Tinta plana sin iluminación del decorado. Hoja QA sobre fondo claro para evaluar bordes; ese fondo no está en los sprites.

Usar allowlist de IDs y estados ya validados. Nunca aceptar rutas, CSS ni reglas generadas por IA. C0–C3 son presets visuales propuestos, no nuevos umbrales de cordura. Mantener capas bajo HUD y fuera de objetivos esenciales, pointer-events:none.

Animación sugerida: dos desplazamientos discretos de 1–2 px, sin bucle estroboscópico; prefers-reduced-motion muestra aparición estática. No se ha integrado ni probado runtime.
