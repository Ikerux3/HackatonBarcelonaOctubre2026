# Comedor

Mesa física por tablero y bastidor; silla idéntica reutilizable y vajilla alpha compartida con cocina. Fondo limpio, anclas de los seis huecos y control de luz en manifest.

Las sillas NO codifican un dueño. Las marcas SVG estrella/vestido usan currentColor; insertarlas como SVG inline o máscara CSS y mostrar solo cuando lo permita el estado oscuro existente. La asignación izquierda/derecha es aleatoria y permanece en runtime. El beauty contiene vajilla solo a modo de montaje, no está horneada en el fondo. La tercera silla se muestra únicamente por phase === final existente.

QA visual 375 px; no ejecución del minijuego. No modificar reglas, tiempos ni pistas.
